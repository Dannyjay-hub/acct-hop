# Building the app and DMG (maintainers)

Needs macOS, a Python 3.13 from python.org (universal2), and an Apple Developer ID certificate.

```bash
python3 -m venv venv && source venv/bin/activate
pip install py2app rumps pillow

# once: save notarization credentials in your own Keychain (asks for an app-specific password)
xcrun notarytool store-credentials acct-hop --apple-id YOU@EXAMPLE.COM --team-id TEAMID

IDENTITY="Developer ID Application: Your Name (TEAMID)" NOTARY_PROFILE=acct-hop ./build_dmg.sh
```

The script builds `dist/acct-hop.app`, signs every binary with the hardened runtime, notarizes and staples
the app, builds `dist/acct-hop-<version>.dmg`, signs it, notarizes and staples it, and prints its SHA-256.
Without `NOTARY_PROFILE` it still builds and signs, but skips notarization. Test builds only.

Check the result: `spctl --assess --type open --context context:primary-signature -vv dist/acct-hop-*.dmg`
should say `accepted` / `source=Notarized Developer ID`.

The version comes from `VERSION` in `sync.py`. The icon is generated by `assets/make_icon.py`.
